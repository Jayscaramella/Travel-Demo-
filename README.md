# Luxe Voyages - Luxury Travel Website

A fully functional, elegant luxury travel website featuring modern design, responsive layout, and interactive elements.

## Features

- **Modern Design**: Elegant and sophisticated UI with luxury color scheme
- **Responsive Layout**: Optimized for all devices (desktop, tablet, mobile)
- **Interactive Elements**: Smooth animations, modals, and dynamic content
- **Featured Destinations**: 6 handpicked luxury travel destinations with detailed information
- **Luxury Experiences**: Showcase of premium travel services
- **Client Testimonials**: Auto-rotating testimonial slider
- **Contact Form**: Functional inquiry form with validation
- **Newsletter Subscription**: Email subscription functionality

## Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- Vanilla JavaScript (ES6+)
- Google Fonts (Playfair Display & Montserrat)
- Unsplash Images

## Getting Started

Simply open `index.html` in any modern web browser to view the website.

### Local Development

1. Clone the repository
2. Open `index.html` in your browser
3. No build process or dependencies required!

## Website Structure

- `index.html` - Main HTML structure
- `styles.css` - All styling and responsive design
- `script.js` - Interactive functionality and form handling
